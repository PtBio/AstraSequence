# 困ったときの確認先と用語

[目次へ](../README.md) · 対象：0.84.0 · 更新：2026-11-05

| 状況 | 確認すること |
|---|---|
| ファイルが最近の一覧にない | 「ファイルを開く」で選び直す |
| 保存できない | 保存先の権限、空き容量、手入力名の長さ、完全保存32 MBの上限を確認 |
| .dnaで保存したい | 「別名で書き出す…」の保存ダイアログでSnapGene DNAを選ぶ |
| 大きなファイルを開けない | 1配列500万残基、配列ファイル8 MB、完全保存32 MBの上限を確認 |
| 配列が表示されるのに編集できない | 20万残基を超える配列を含む文書は閲覧専用。選択・コピー・検索を使う |
| 開き直すと選択部分が画面にない | 下部の選択座標を確認し、Go to／Select Rangeや検索で表示する |
| Featureの変更が保存されない | 独立窓の「適用」を押してから文書を保存 |
| 酵素が表示されない | トラック表示、供給元、グループ、検索完了を確認。「判定保留」と0件を区別する |
| .dnaがMSAへ追加できない | 分子種・20,000残基の候補上限・画面のエラーを確認 |
| 候補はあるがアライメントできない | 選択本数、同じ分子種か、方式別の計算上限を確認 |
| 実行が時間切れになる | 配列数・長さ・方式を見直す。元入力を残して再試行 |
| 配列とアライメントの番号が違う | gap込みの列番号と元残基の座標を区別 |
| マップが見えない | 表示メニューのトラック・ミニ全体マップを確認 |

## 用語

| 用語 | 意味 |
|---|---|
| bp / nt / aa | 塩基対／ヌクレオチド／アミノ酸の長さの表記 |
| Feature | 配列の領域に付けた名前・種類・位置などの注釈 |
| CDS | タンパクをコードする領域として扱う注釈 |
| Primer / oligo | 鋳型へ結合させる短い核酸配列。登録配列は5′→3′ |
| テンプレート結合部 | Primerのうち鋳型へ相補的に結合する部分。5′側の付加配列とは区別する |
| 閲覧専用 | 表示・選択・コピー・検索はでき、配列や注釈は変更できない状態 |
| 逆相補 | 逆方向に読み、各塩基を相補塩基へ置き換えた配列 |
| topology | 配列が線形か環状かという保存情報 |
| gap | アライメントで対応付けのために置く空欄（通常はハイフン） |
| コンセンサス | 各列の残基を集約して得る代表配列 |

解決しない場合は[Issues](https://github.com/PtBio/AstraSequence/issues)へ、アプリの版、OS、操作手順、期待した結果、実際の結果を記載してください。公開Issueには機密配列・認証情報・個人情報を含めず、再現用の合成データがあれば添えてください。
