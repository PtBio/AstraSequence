# 対応範囲と画面の出典

[目次へ](../README.md) · 対象：0.84.0 · 更新：2026-11-05

操作説明は0.84.0に合わせて更新しています。掲載画像の中心は、macOS上のAstraSequence 0.79.2を操作して撮影したものです。各図に撮影版を記載しています。保存・書き出しなど、現行版と画面が異なる操作は本文の手順に従ってください。

画像と練習用配列には内蔵合成サンプルや公開用の練習データを使用しています。実験データの解析結果ではありません。

0.79.2の撮影時には、保存名、配列・Feature表示、酵素設定、FASTA追加、MAFFT Auto実行、アライメント結果・書き出し画面を確認しました。2026-11-05にはmacOSの0.84.0検証用アプリで、5 Mbの表示、マップと本文のドラッグ、末端への移動、コピー・検索、.as保存・再読み込みを確認しています。検証用アプリは標準版と同じ描画バイナリを使用しています。

再読み込み時に選択範囲は保持されますが、画面内のスクロール位置は完全には復元されない場合があります。対象位置が見えない場合は、[選択位置へ戻る手順](editing.md#開き直した後に選択位置を見つける)を参照してください。

Windows／Linux／モバイルの実機手順、IME・VoiceOverは今回確認していません。利用する配布物の対応OSを確認してください。このリポジトリは操作ガイド用で、アプリ配布ZIPは収録していません。

画像のファイル名・ハッシュは[画像一覧](screenshots.json)に記録しています。利用者の配列、第三者アプリの参考スクリーンショット、開発用ソースコードは収録していません。

PCR・消化の2画像は旧レイアウトの自動UIテスト画像で、各図に明記しています。現行版の実機画像とは区別してください。
