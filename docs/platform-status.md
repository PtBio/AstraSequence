# 対応範囲

v0.63.0はApple Silicon向けのローカルMac Appを用意する版です。アドホック署名で、一般配布用署名・Apple公証は未実施です。Macの初期開始画面とウィンドウ枠だけ実起動で確認しました。物理キー、IME、ドラッグ、保存ダイアログ、複数窓操作と保存枠の復帰は当版の実機受入が残っています。

Windows／iOS／Androidは開発対象であり、当版の実機ビルドを確認した配布版はありません。390幅のheadless画像をモバイル完成の証拠とはしません。多言語化も計画段階で、現行は日本語中心です。

ローカル解析の候補は実験効率・特異性・安全性を検証した結果ではありません。Privateを既定とし、Skyの公開ID取得やBLAST等はそれぞれ送信対象と同意条件を確認してください。
