# 新しくなったこと

## v0.63

大きなAstraSequenceのタイトルと版、星とDNAの生成ロゴ、元の比率を保ったPtBioロゴを開始画面へ追加しました。同梱ガイドはオフラインでも読めます。動画と公開ガイドは公開準備中です。

標準Flutterホストと代替Swiftホストの初期サイズを共通化しました。旧版の小さい保存枠を初期値として引き継がず、新しい保存枠は利用者の位置とサイズを尊重します。起動スクリプトは版を確認して正しいアプリを選びます。

最近のファイルは、現在アクセスを確認できたものだけを選択可能にします。表示はファイル名で、フルパスを常時表示しません。永続アクセス許可は追加していません。

## v0.62

認識範囲と切断面に基づく酵素名の集約、読みやすい方向矢印、リニアの近接ラベル、左欄の折りたたみ、Mac向けの独立注釈編集を追加しました。

## v0.60〜v0.61

タンパク物性、自動集計、10残基区切り、全注釈一覧、編集の件数確認、共有Undo、入力ソースのスコープ制御を追加しました。実機で未確認の範囲はユーザーガイドを参照してください。
