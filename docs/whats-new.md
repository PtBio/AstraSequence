# 新しくなったこと

[目次へ](../README.md) · 対象：0.84.0 · 更新：2026-11-06

## 0.84.0：大きな配列を表示・選択する

500万残基までの配列を閲覧できるようになりました。大きなFASTA・GenBank・SnapGeneファイルの読み込みと保存に対応し、範囲選択やドラッグの操作を改善しました。20万残基を超える配列を含む文書は閲覧専用です。

## 保存メニューを整理

「別名で保存…」は.as／.asalnの完全保存に使います。SnapGene、GenBank、FASTAなどへの変換は「別名で書き出す…」から行い、macOSの保存ダイアログ内で形式を選びます。[保存と書き出し](saving.md)に現行の手順をまとめました。

## プライマーの表記を変更

鋳型へ相補的に結合する部分を「テンプレート結合部」と表記するようになりました。[Primer・PCR](primers.md)では、5′側の付加配列との違いも説明しています。

## これまでの主な機能

Featureの形状・セグメント・CDS翻訳、供給元×酵素グループ、配列ビューと連動マップ、核酸・タンパクのマルチプルアライメント、.asaln保存を利用できます。長い保存候補名は自動で短縮されます。
