# ユーザーガイド

## 文書と全体マップ

ファイル別タブの選択と履歴を保持します。全体マップは文字配列を省いた模式図です。保存topologyを優先し、必要に応じ表示形式だけを手動変更できます。生物学的な部位探索は保存topologyに従います。左のトラック欄は折りたたみ可能です。

## 注釈と独立ウィンドウ

Feature／Primerは既存の向き・join・complementを保持します。対応するMac版は独立注釈ウィンドウを最大4個開けます。同じ注釈は既存窓を再表示します。主画面の文書が変わると保守的に競合を表示し、古い下書きから別の対象へ適用しません。適用前の下書きは.asの保存には含まれません。

## Undoと大きな編集

同種の連続入力は900ms未満でまとめます。カーソル移動や別操作で区切られます。100残基を超える削除・挿入には件数とUndoを表示し、設定で事前確認も選べます。Cutは承認後にコピーし、Clipboard失敗時には削除しません。

## タンパク物性

タンパク文書だけの物性タブで、全長と選択のMW・pI・pH電荷・ε280などを端末内で計算します。モデルと入力条件、未対応記号を確認してください。10残基区切りは表示だけで、コピーする配列や座標を変えません。

## 保存・アクセス・通信

完全保存は.asです。最近のファイルのパスは許可そのものではありません。永続アクセス許可は追加しておらず、再起動後にアクセスできない項目は最近の一覧へ出しません。ファイル選択で再度許可できます。通信モードと外部送信の内容は、各確認画面で確認してください。

## 確認した範囲

自動回帰・静的解析・Apple Siliconのローカル構築と署名を確認します。Macの実複数窓・物理キー・IME・OS保存選択、Windows／Android／iOSの実機ビルドは未確認です。Apple公証済みの配布物ではありません。
