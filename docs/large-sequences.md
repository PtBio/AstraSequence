# 5 Mbまでの大きな配列を閲覧する

[目次へ](../README.md) · 対象：0.84.0 · 更新：2026-11-05

0.84.0では、1配列あたり500万残基まで表示できます。DNAなら約5 Mbです。全文を読み込んだうえで、配列ビューには最大5,000文字の区間を表示します。スクロールや座標指定で表示する区間を変えます。

## 表示と編集の上限を確認する

| 対象 | 上限・動作 |
|---|---|
| 1配列の表示 | 500万残基まで |
| 配列・注釈の編集 | 20万残基まで。これを超える配列を含む文書は閲覧専用 |
| ローカル配列ファイル | FASTA・GenBank・SnapGeneなどは1ファイル8 MBまで |
| 完全保存 | .as／.asalnなどは注釈や履歴を含め1ファイル32 MBまで |

ここでMBは100万バイトです。配列長とファイル容量は別々に判定します。注釈や空白を多く含むファイルは、500万残基以下でも容量上限を超える場合があります。上限を超えた入力は切り詰めずに停止します。

閲覧専用でも範囲選択、コピー、検索、移動、.asへの完全保存を利用できます。画面上部に閲覧専用の案内が出ているときは、入力・置換や注釈変更を行えません。

## マップで広い範囲を選ぶ

1. 「ファイルを開く」で対象配列を読み込みます。
2. 「全体マップ」タブで配列名と全長を確認します。
3. マップ上をドラッグし、画面下部の選択座標、長さ、GCを確認します。逆方向のドラッグも利用できます。
4. 「配列」タブへ切り替え、必要な部分を文字で確認します。

細かい位置の調整には、次の座標指定を使ってください。

## 末端へ移動し、選んだ配列をコピーする

500万塩基ちょうどの配列で、末端8塩基を選ぶ例です。

1. 「編集 → 選択・移動 → Select Range · 範囲を選択…」を開きます。
2. 開始に4999993、終了に5000000を入力します。自分の配列では全長に合わせて置き換えます。
3. 「範囲を選択」を押し、画面下部が「選択4999993–5000000・8 bp」になっていることを確認します。
4. 「コピー」またはMacの⌘Cで選択した配列をコピーします。
5. 配列を検索するには「編集 → 検索」または⌘Fを使います。文字列を入力し、Enterで検索を実行します。

座標は1始まりで終了位置を含みます。500万塩基の確認用合成配列では、末端8塩基のGATTACAAをコピーし、検索で同じ位置に1件見つかることを確認しました。検索の一致数は入力配列によって変わります。

## 保存して、開き直す

「保存」または「ファイル → 別名で保存…」から.asへ保存します。保存した文書を閉じ、最近使ったファイルか「ファイルを開く」から開き直します。選択位置と配列長を確認してください。[保存と外部形式への書き出し](saving.md)で、それぞれのメニューの使い分けを説明しています。

選択範囲は保持されますが、画面内のスクロール位置は保存前と同じにならない場合があります。選択位置が見えていなければGo to／Select Range、または検索で表示してください。

## 解析の上限は別に確認する

表示できる長さと、解析できる長さは同じではありません。例えば制限酵素の切断数解析は20万残基までです。大配列で「判定保留」と表示された場合は、切断部位が0件という意味ではありません。

マルチプルアライメントは、各配列の長さ・合計長・本数・アルゴリズムごとに上限があります。[アライメントの入力上限](alignment.md#長い配列を扱うときの上限)を確認してください。
